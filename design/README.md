# Windows UI design prototype

Утверждённый V3 прототип интерфейса Telegram Desktop. Это дизайн-слой, а не патч C++/Qt.

## Файл

- `telegram-desktop-windows-ui.html` - самодостаточный интерактивный прототип.
- Открывается локально в браузере, без сервера и внешних ресурсов.
- Для чистого скриншота без splash и toast: `?clean=1`.
- Параметры демо: `?theme=light|dark`, `?density=compact|comfortable`, `?view=menu|contacts|calls|settings|state`, `?state=loading|empty|error|populated`, `?open=1`.

## Компоновка

Официальная компоновка Telegram Desktop сохранена:

- Слева сверху гамбургер-меню и поле поиска.
- Ниже закреплённые чаты и «Все чаты» строками.
- В шапке диалога: назад на узком окне, аватар, имя, статус; справа поиск, звонок, информация, ещё.
- В composer: вложение, поле ввода, эмодзи, отправка.
- Главное меню: профиль, новая группа, новый канал, контакты, звонки, избранное, архив, настройки.
- Настройки: отдельное окно с левым списком разделов и правой областью содержимого.

## Состояния и взаимодействия

- Загрузка, пустой список, ошибка и заполненные данные.
- Toast и splash.
- Поиск по чатам и сообщениям.
- Светлая и тёмная темы.
- Компактная и комфортная плотность.
- Горячие клавиши: `Ctrl+K`, `Ctrl+,`, `Ctrl+M`, `Esc`, `Enter`.
- Адаптив: две колонки на десктопе, одна колонка с кнопкой «Назад» на узких окнах.

## Проверка

- Основной JavaScript проходит `node --check`.
- DOM-аудит: нет дублирующихся ID, все кнопки и поля имеют подписи, внешних ресурсов нет.
- Скриншоты: 1440x900, 1024x768, 390x844; светлая и тёмная темы; главное меню, настройки, контакты, мобильный диалог.
- Визуальный стиль проверен в Firefox headless.

## C++/Qt status

Визуальные изменения уже внесены в код и собраны:

- `Telegram/lib_ui/ui/colors.palette`: нейтральная светлая палитра, акцент `#0078D7`;
- `Telegram/lib_ui/ui/style/style_core_icon.cpp`: глобальный масштаб иконок 1.1;
- `Telegram/SourceFiles/dialogs/dialogs.style`: компактные строки чата 60 px, аватар 44 px;
- `Telegram/Resources/night.tdesktop-theme`: нейтральная тёмная палитра, акцент `#0F6CBD`.

Патчи:

- `patches/lib_ui-windows-theme.diff`;
- `patches/windows-visual-theme.diff`.

Сборка Release x64: 0 ошибок, 0 предупреждений, 4 мин 41 с. `Telegram.exe` запускается с временным профилем. Официальная геометрия `Window::Controller`, `Dialogs::Widget`, `HistoryView::TopBarWidget` и `ComposeControls` не менялась.
